      I'm Sporty. Start your camera, pick a movement, and I'll count reps and watch your form. Ask me anything once you've done a set or two.
      Pose landmarks are processed on-device via MediaPipe; video never leaves your browser. Rep counting is a threshold state machine over joint angles (numpy-style vector math, ported to JS). Coaching runs Offline by default using built-in rules — switch to Online in the Connection panel and add an OpenRouter API key to route coaching through a real LLM of your choice. The key lives only in this tab's memory and is sent solely to OpenRouter. Session history lives in memory for this tab only; wire the same schema into a small SQLite backend to persist it across visits, as sketched in the original architecture.
